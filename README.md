# AI Editor Configs

> Production-tested configuration files for AI coding editors. Copy, customize, ship.

By [RunAICode.ai](https://runaicode.ai) — AI coding tools reviewed by engineers.

## What's Inside

```
configs/
├── cursor/
│   ├── .cursorrules          # Project-level Cursor rules
│   ├── cursorrules-python.md # Python-specific rules
│   ├── cursorrules-react.md  # React/Next.js rules
│   └── cursorrules-devops.md # DevOps/infrastructure rules
├── claude-code/
│   ├── CLAUDE.md             # Claude Code project instructions template
│   ├── claude-md-python.md   # Python project template
│   └── claude-md-fullstack.md # Full-stack template
├── copilot/
│   ├── .github/copilot-instructions.md
│   └── workspace-settings.json
└── windsurf/
    └── .windsurfrules
```

## Quick Start

```bash
# Clone and copy the config you need
git clone https://github.com/runaicode/ai-editor-configs.git
cp ai-editor-configs/configs/cursor/.cursorrules ./your-project/
```
